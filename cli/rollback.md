# tofupilot rollback
URL: /docs/cli/rollback

Revert the TofuPilot CLI to the previously installed version after a bad upgrade, without touching credentials or queued runs.

***

title: tofupilot rollback
description: "Revert the TofuPilot CLI to the previously installed version after a bad upgrade, without touching credentials or queued runs."
sidebarTitleCode: tofupilot rollback
------------------------------------

The `rollback` command reverts to the previously installed CLI version.

```bash title="rollback"
tofupilot rollback
```
