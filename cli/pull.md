# tofupilot pull
URL: /docs/cli/pull

Fetch the latest TofuPilot deployments from the dashboard before running a procedure so the station executes the newest version.

***

title: tofupilot pull
description: "Fetch the latest TofuPilot deployments from the dashboard before running a procedure so the station executes the newest version."
sidebarTitleCode: tofupilot pull
--------------------------------

The `pull` command fetches the latest [Deployments](/docs/deployments) from the dashboard. Run it before `run` to pick up deployments that landed since the last sync.

```bash title="pull"
tofupilot pull
```
