# tofupilot logout
URL: /docs/cli/logout

Clear stored TofuPilot credentials from the CLI without deleting the local data directory or any queued runs.

***

title: tofupilot logout
description: "Clear stored TofuPilot credentials from the CLI without deleting the local data directory or any queued runs."
sidebarTitleCode: tofupilot logout
----------------------------------

The `logout` command clears stored credentials, and it does not remove the local data directory or queued runs.

```bash title="logout"
tofupilot logout
```
