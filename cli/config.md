# tofupilot config
URL: /docs/cli/config

Inspect the local TofuPilot CLI configuration including dashboard URL, station ID, terminal and kiosk UI modes, and runtime settings.

***

title: tofupilot config
description: "Inspect the local TofuPilot CLI configuration including dashboard URL, station ID, terminal and kiosk UI modes, and runtime settings."
sidebarTitleCode: tofupilot config
----------------------------------

The `config` command prints local CLI configuration, including the dashboard URL, station ID, terminal UI mode, kiosk UI mode, and runtime settings.

```bash title="config"
tofupilot config
```

The output is human-readable by default, and `--json` switches to JSON.
