# tofupilot update
URL: /docs/cli/update

Upgrade the TofuPilot CLI to the latest release in place, with an automatic background check that prompts when a new version ships.

***

title: tofupilot update
description: "Upgrade the TofuPilot CLI to the latest release in place, with an automatic background check that prompts when a new version ships."
sidebarTitleCode: tofupilot update
----------------------------------

The `update` command checks for a newer CLI release and installs it in place. The CLI also checks in the background and prompts when an update is available.

```bash title="update"
tofupilot update
```
